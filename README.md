# No Stone Foundation Website
https://ezmar001.github.io/nostone-foundation-website/
## Project Overview

This repository contains the static website for **No Stone Foundation**, a non-profit organisation dedicated to empowering underprivileged youth through education, skills development, and community mentorship.

## Website Goals and Objectives

- Increase community awareness of the foundation's programmes
- Provide a platform for volunteer recruitment
- Showcase impact and success stories
- Offer accessible contact channels for donors and partners

## Target Audience

- Prospective volunteers
- Donors and sponsors
- Community members seeking programme information
- Partner organisations

## Key Features and Functionality

- **5 responsive HTML pages**: Homepage, About Us, Programmes, Volunteer Enquiry, Contact
- **Consistent navigation** across all pages via persistent header menu
- **Volunteer enquiry form** with HTML5 validation (required fields)
- **Responsive design** adapting to desktop and mobile screens
- **Semantic HTML structure** for accessibility
